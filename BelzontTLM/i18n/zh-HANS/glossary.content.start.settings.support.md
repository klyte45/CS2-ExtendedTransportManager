## 获取帮助

XTM 选项页面显示已安装的 mod 版本，并提供论坛、源存储库、翻译文件夹和日志文件夹的快捷方式。

使用论坛获得玩家支持和讨论：[XTM 论坛主题](https://forum.paradoxplaza.com/forum/threads/xtm-extended-transport-manager.1651555/)

使用 GitHub 存储库进行源代码和技术问题跟踪：[klyte45/CS2-ExtendedTransportManager](https://github.com/klyte45/CS2-ExtendedTransportManager)

## 包含哪些内容

在寻求帮助之前，请记录显示的 XTM 版本以及重现问题所需的步骤。对于错误，请暂时启用调试日志记录，重现问题一次，然后使用 **转到日志文件夹** 找到 XTM 日志。

包括游戏版本、XTM 版本、相关模组列表、受影响的保存上下文、屏幕截图和日志文件。之后将日志记录恢复为正常。
