## Obteniendo ayuda

La página de opciones de XTM muestra la versión mod instalada y proporciona accesos directos al foro, al repositorio de origen, a la carpeta de traducción y a la carpeta de registro.

Utilice el foro para soporte y debate para jugadores: [Tema del foro XTM](https://forum.paradoxplaza.com/forum/threads/xtm-extended-transport-manager.1651555/)

Utilice el repositorio de GitHub para el código fuente y el seguimiento de problemas técnicos: [klyte45/CS2-ExtendedTransportManager](https://github.com/klyte45/CS2-ExtendedTransportManager)

## Qué incluir

Antes de pedir ayuda, registre la versión de XTM que se muestra y los pasos necesarios para reproducir el problema. En caso de errores, habilite temporalmente el registro de depuración, reproduzca el problema una vez y use **Ir a la carpeta de registro** para localizar el registro XTM.

Incluya la versión del juego, la versión XTM, la lista de modificaciones relevantes, el contexto de guardado afectado, capturas de pantalla y el archivo de registro. Regrese el registro a Normal después.
