Habilite **Mostrar botón de paletas del editor** en las opciones de modificación antes de ingresar al editor de un juego. Esta configuración está habilitada de forma predeterminada y se aplica cuando se carga el editor.

Seleccione el icono XTM en la barra de herramientas del editor para abrir el cuadro de diálogo **Paletas disponibles** que se puede arrastrar. Seleccione otra herramienta de edición cuando haya terminado.

![Diálogo de paletas disponibles abierto desde la herramienta XTM en la barra de herramientas del Editor de activos](coui://xtm.k45/UI/images/xtm-editor-palettes.jpg)

## Administrar paletas

Cree una paleta, importe un archivo `.hex` o importe un ajuste preestablecido desde la biblioteca incorporada de XTM. Seleccione una paleta para cambiarle el nombre, eliminarla, agregar o eliminar colores, editar colores individuales, arrastrar colores a un nuevo orden, mezclarlos o agregar otra paleta.

También puede copiar la paleta como un valor RGB por línea, pegar y reemplazar sus colores, o pegar y agregar colores. Presione **Guardar cambios** para conservar las ediciones de color o **Restablecer cambios** para descartar las ediciones no guardadas.

La sección inferior asigna una paleta a cada tipo de transporte de pasajeros o carga disponible. Seleccione **Color automático deshabilitado** cuando ese tipo no deba usar una paleta.

## Límites

Una paleta puede contener como máximo 500 colores. Las importaciones utilizan archivos `.hex` que contienen valores RGB de seis dígitos. El editor trabaja con la colección de paletas del mundo actual; utilice archivos de disco o la biblioteca integrada cuando necesite una fuente de paleta explícita.
