Elija **Importar paleta** para abrir un selector de archivos para archivos `.hex`. Comienza en la carpeta de paleta de XTM e incluye un marcador **XTM: Biblioteca** para ajustes preestablecidos incluidos.

Un archivo `.hex` contiene un color RGB de seis dígitos por línea, con o sin `#`. El nombre del archivo se convierte en el nombre de la paleta de la ciudad. Las líneas en blanco o no válidas se ignoran y se importan como máximo los primeros 500 colores válidos.

Importar crea una nueva paleta de ciudad, incluso cuando una paleta tiene el mismo nombre. Para combinar colores con una paleta existente, selecciónela y use **Agregar paleta**.
