Abilita **Mostra pulsante tavolozze editor** nelle opzioni mod prima di accedere a un editor di gioco. Questa impostazione è abilitata per impostazione predefinita e viene applicata al caricamento dell'editor.

Seleziona l'icona XTM nella barra degli strumenti dell'editor per aprire la finestra di dialogo trascinabile **Tavolozze disponibili**. Seleziona un altro strumento di editor quando hai finito.

![Finestra di dialogo delle tavolozze disponibili aperta dallo strumento XTM nella barra degli strumenti dell'Editor risorse](coui://xtm.k45/UI/images/xtm-editor-palettes.jpg)

## Gestisci le tavolozze

Crea una tavolozza, importa un file `.hex` o importa un preset dalla libreria incorporata di XTM. Seleziona una tavolozza per rinominarla, eliminarla, aggiungere o rimuovere colori, modificare singoli colori, trascinare i colori in un nuovo ordine, mescolarli o aggiungere un'altra tavolozza.

Puoi anche copiare la tavolozza come un valore RGB per riga, incollare e sostituire i suoi colori oppure incollare e aggiungere colori. Premi **Salva modifiche** per mantenere le modifiche ai colori oppure **Ripristina modifiche** per eliminare le modifiche non salvate.

La sezione inferiore assegna una tavolozza a ciascun tipo di trasporto passeggeri o merci disponibile. Seleziona **Colore automatico disabilitato** quando quel tipo non deve utilizzare una tavolozza.

## Limiti

Una tavolozza può contenere al massimo 500 colori. Le importazioni utilizzano file ".hex" contenenti valori RGB a sei cifre. L'editor lavora con la collezione di tavolozze del mondo attuale; utilizzare i file su disco o la libreria incorporata quando è necessaria un'origine tavolozza esplicita.
