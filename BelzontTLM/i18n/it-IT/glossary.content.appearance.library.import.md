Scegli **Importa tavolozza** per aprire un selettore di file per i file `.hex`. Inizia nella cartella delle palette di XTM e include un segnalibro **XTM: Library** per i preset in bundle.

Un file ".hex" contiene un colore RGB a sei cifre per riga, con o senza "#". Il nome del file diventa il nome della tavolozza della città. Le righe vuote o non valide vengono ignorate e vengono importati al massimo i primi 500 colori validi.

L'importazione crea una nuova tavolozza di città, anche quando una tavolozza ha lo stesso nome. Per combinare i colori con una tavolozza esistente, selezionala e utilizza **Aggiungi tavolozza**.
