## 내장 번역

XTM은 지원되는 모든 게임 로캘의 기본 언어로 영어를 로드합니다. 현재 패키지에는 포르투갈어(브라질) 및 한국어 CSV 번역도 포함되어 있습니다.

번역된 키가 누락되거나 비어 있으면 영어 CSV 값이 사용됩니다.

## CSV 파일

기본 **i18n.csv**에는 언어 열이 포함되어 있습니다. **ko-KR.csv**와 같은 별도의 언어 파일은 해당 언어가 기본 파일에 열이 없는 경우에만 사용됩니다.

CSV 파일은 탭으로 구분되며 헤더 행이 필요합니다. 중괄호와 같은 서식 지정 자리 표시자를 변경하지 않고 유지하세요. CSV 값에 줄 바꿈이나 탭이 필요한 경우 리터럴 시퀀스 \n 및 \t를 사용합니다.

## 마크다운 용어집 본문

긴 용어집 항목은 **i18n/en-US**에서 키당 하나의 Markdown 파일을 사용합니다. 다른 언어는 해당 언어 폴더 아래에 개별 항목을 오버레이할 수 있습니다. 누락된 번역된 Markdown 파일은 자동으로 영어 본문을 유지합니다.

각 Markdown 파일에는 **key:** 또는 **entry:** 뒤에 조립된 현지화 키가 포함된 머리말이 필요합니다.

Markdown 본문은 CSV 항목 다음에 로드되므로 Markdown 파일은 동일한 키를 사용하여 CSV 값을 재정의합니다.

## 번역 테스트

**번역 폴더로 이동**을 사용하여 설치된 XTM i18n 디렉토리를 엽니다. 파일을 편집한 후 게임을 다시 시작하지 않고도 **번역 다시 로드**를 사용하여 모든 XTM 현지화 소스를 제거하고 다시 빌드할 수 있습니다.
