XTM은 경로의 연결된 정류장 엔터티에 게임의 외부 연결 구성 요소가 있는 경우 외부 연결을 인식합니다.

**지구 경계**를 활성화하면 XTM은 외부 연결 정류장 주위에 지구 구분선을 그립니다. 해당 정류장에 해결된 구역이 없으면 해당 경계 라벨은 **Colossal Nation: {정류장 이름}**으로 금색으로 표시됩니다. 정지 표시 자체는 일반 정지 표시처럼 그려집니다.

외부 연결 상태는 경로 순서를 변경하거나 자동으로 정류장을 종점으로 만들지 않습니다. 대칭 반 주행 모드에서는 외부 연결이 표시된 경로 반에 속하는 경우에만 표시됩니다.
