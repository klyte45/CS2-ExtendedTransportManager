## 교통 개요

**기본적으로 XTM 라인 목록 사용**은 기본적으로 활성화됩니다. 활성화되면 운송 개요가 XTM 모드에서 열립니다. 비활성화되면 원래 게임 테이블과 함께 열립니다.

패널 헤더의 XTM 버튼은 항상 사용할 수 있는 상태로 유지됩니다. 전환하면 현재 패널 세션만 변경됩니다. 운송 개요를 다시 열면 구성된 기본값을 다시 읽습니다.

다른 XTM 화면의 직접 링크는 기본값이 비활성화된 경우에도 XTM 모드에서 운송 개요를 계속 열 수 있습니다.

## 편집기 팔레트 도구

**편집기에서 팔레트 표시 버튼**은 기본적으로 활성화되어 있습니다. XTM 팔레트 도구를 편집기 도구 모음에 추가하여 사용 가능한 팔레트 인터페이스를 엽니다.

이 옵션은 편집기 모드에 들어갈 때 평가됩니다. 변경 후 Editor를 종료했다가 다시 시작하세요.

XTM 설정이 재설정되면 두 UI 기본값이 모두 활성화로 복원됩니다.
