게임 편집기에 들어가기 전에 모드 옵션에서 **편집기 팔레트 표시 버튼**을 활성화하세요. 이 설정은 기본적으로 활성화되어 있으며 편집기가 로드될 때 적용됩니다.

편집기 도구 모음에서 XTM 아이콘을 선택하여 드래그 가능한 **사용 가능한 팔레트** 대화 상자를 엽니다. 완료되면 다른 편집기 도구를 선택하십시오.

![자산 편집기 도구 모음의 XTM 도구에서 열린 사용 가능한 팔레트 대화 상자](coui://xtm.k45/UI/images/xtm-editor-palettes.jpg)

## 팔레트 관리

팔레트를 생성하거나 `.hex` 파일을 가져오거나 XTM 내장 라이브러리에서 사전 설정을 가져옵니다. 팔레트를 선택하여 이름을 바꾸거나, 삭제하거나, 색상을 추가 또는 제거하거나, 개별 색상을 편집하거나, 색상을 새 순서로 드래그하거나, 섞거나, 다른 팔레트를 추가할 수 있습니다.

팔레트를 한 줄에 하나의 RGB 값으로 복사하고 해당 색상을 붙여넣고 바꾸거나 색상을 붙여넣고 추가할 수도 있습니다. 색상 수정사항을 유지하려면 **변경사항 저장**을 누르고, 저장되지 않은 수정사항을 삭제하려면 **변경사항 재설정**을 누르세요.

하단 섹션에서는 사용 가능한 각 승객 또는 화물 운송 유형에 팔레트를 할당합니다. 해당 유형이 팔레트를 사용하지 않아야 하는 경우 **자동 색상 비활성화**를 선택하세요.

## 한도

팔레트에는 최대 500개의 색상이 포함될 수 있습니다. 가져오기에서는 6자리 RGB 값이 포함된 `.hex` 파일을 사용합니다. 편집기는 현재 세계의 팔레트 컬렉션으로 작업합니다. 명시적인 팔레트 소스가 필요할 때 디스크 파일이나 내장 라이브러리를 사용하십시오.
