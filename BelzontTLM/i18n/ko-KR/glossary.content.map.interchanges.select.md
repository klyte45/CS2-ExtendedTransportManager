해당 경로로 이동하려면 연결선 쉴드를 선택하세요. 게임은 경로 자체를 선택하므로 선택한 정보 패널과 선형 지도가 해당 경로로 전환되고 새로 선택한 서비스에 맞게 스트립이 재구성됩니다.

실드를 선택해도 연결이 표시된 정지점은 선택되지 않습니다. 해당 환승지점을 검사하고 싶을 때에는 정지마커를 별도로 선택하세요.

## 경로 식별

경로의 전체 이름을 읽으려면 방패 위로 마우스를 가져가세요. 방패에는 운송 형태, 현재 색상, 표시 식별자 또는 경로 번호, 화물 배지 및 서비스 상태 배지가 표시됩니다.

## 탐색하는 동안 집중하세요

정류장이나 차량을 선택하면 지도에서 해당 선택과 관련 없는 행이 사라지므로 관련 정류장은 계속 강조됩니다. 표시된 경로로 선택 항목을 되돌리려면 스트립 위의 기본 경로 실드를 선택하세요.
