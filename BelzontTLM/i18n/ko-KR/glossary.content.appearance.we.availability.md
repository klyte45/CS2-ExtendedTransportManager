XTM 대상 블라인드에는 **Write Everywhere**(`BelzontWE`)가 필요합니다. 해당 모드가 있고 XTM이 통합 후크를 연결할 수 있으면 모든 전송 라인에 블라인드를 사용할 수 있습니다.

경로를 선택하고 **Line Data**를 엽니다. Write Everywhere 버튼은 드래그 가능한 **Write Everywhere - 맞춤형 블라인드** 창을 엽니다. 정지 또는 차량 선택 시에는 버튼이 표시되지 않습니다.

Write Everywhere가 없으면 버튼과 대상 숨김 편집을 사용할 수 없습니다. 이 전체 **Write Everywhere** 백과사전 카테고리도 생략되었습니다.
