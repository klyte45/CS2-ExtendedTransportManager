## Transportation Overview

**Use XTM line listing by default** is enabled by default. When enabled, Transportation Overview opens in XTM mode. When disabled, it opens with the original game table.

The XTM button in the panel header always remains available. Switching it changes only the current panel session; reopening Transportation Overview reads the configured default again.

A direct link from another XTM screen can still open Transportation Overview in XTM mode even when the default is disabled.

![XTM options page showing the default listing mode and editor palette button toggles](coui://xtm.k45/UI/images/xtm-settings-ui-defaults.jpg)

## Editor palette tool

**Show palettes button in Editor** is enabled by default. It adds the XTM palette tool to the Editor toolbar, where it opens the Available palettes interface.

This option is evaluated when Editor mode is entered. Leave and re-enter the Editor after changing it.

Both UI defaults are restored to enabled when XTM settings are reset.
