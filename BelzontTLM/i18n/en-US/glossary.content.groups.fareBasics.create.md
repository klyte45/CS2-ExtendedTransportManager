Open **Transportation Overview**, choose **Change mode**, then **Fare Groups**. Select the plus button beside Groups to create a group.

A new group is selected automatically, starts with the game's normal default ticket fare, and uses **Unnamed group** until renamed. Names save when editing ends; a blank name returns to the localized unnamed label.

Each group card shows its name, default fare, and number of member lines. Select a card to edit it.

Use a card's trash button and confirm to delete the group. Its lines stop belonging to that group, but retain the last fare XTM applied. Review their ticket prices after deletion.
