Vehicles start hidden on the XTM linear map. Select the **Vehicles** toolbar button to display every active vehicle returned for the route. Vehicle and connecting-line overlays are mutually exclusive, and displaying vehicles expands a symmetric half-trip map to the full route.

Each marker is placed between the map's evenly spaced stops using its current progress through that route segment. Its label shows the vehicle name and internal entity number.

The marker fill, outline, and hover tooltip show current load against capacity. Select a marker to focus the vehicle and open its **Vehicle Data** section.
