Select a transport route and find its line visualizer in the **Selected Info Panel**. Use the XTM button at the left of the visualizer toolbar to switch between the game's route sketch and the XTM linear map.

## Map controls

The map can show distances, district boundaries, vehicles, connecting lines, platform crowding, segment occupancy, a white background, and a shortened half-trip view for symmetric routes.

![XTM linear map with the toolbar and the distance, district, connection, crowding, and occupancy overlays enabled](coui://xtm.k45/UI/images/xtm-linear-map-overlays.jpg)

Segment occupancy can be hidden or shown for the current hour, daily average, or one of six four-hour periods. Select a segment's occupancy value to open its historical chart.

![Segment occupancy detail opened from the linear map, with its time chart and daily average](coui://xtm.k45/UI/images/xtm-linear-map-segment-detail.jpg)

## Navigate from the map

Select a stop to focus it and open Stop Data. When vehicles are displayed, select one to focus it and open Vehicle Data. Select a connecting-line shield to move to that route. Select the main route shield to return to the route.

## Defaults and limits

XTM map mode starts enabled. Distances, districts, connecting lines, platform crowding, current-hour segment occupancy, and symmetric half-trip mode start enabled; vehicles and the white background start disabled.

Vehicles and connecting lines are mutually exclusive. Half-trip mode is used only for a detected symmetric route while vehicles are hidden.
