Enable **Show editor palettes button** in the mod options before entering a game editor. This setting is enabled by default and is applied when the editor loads.

Select the XTM icon in the editor toolbar to open the draggable **Available palettes** dialog. Select another editor tool when you are finished.

## Manage palettes

Create a palette, import a `.hex` file, or import a preset from XTM's embedded library. Select a palette to rename it, delete it, add or remove colors, edit individual colors, drag colors into a new order, shuffle them, or append another palette.

You can also copy the palette as one RGB value per line, paste and replace its colors, or paste and append colors. Press **Save changes** to persist color edits, or **Reset changes** to discard unsaved edits.

The lower section assigns a palette to each available passenger or cargo transport type. Select **Auto color disabled** when that type should not use a palette.

## Limits

A palette can contain at most 500 colors. Imports use `.hex` files containing six-digit RGB values. The editor works with the current world's palette collection; use disk files or the embedded library when you need an explicit palette source.
