Select a connecting-line shield to move to that route. The game selects the route itself, so the Selected Info Panel and linear map switch to it and the strip is rebuilt for the newly selected service.

Selecting a shield does not select the stop where the connection was shown. Select the stop marker separately when you want to inspect that transfer point.

## Identifying a route

Hover over a shield to read the route's full name. The shield shows its transport shape, current color, display identifier or route number, cargo badge, and service-state badge.

## Focus while browsing

When a stop or vehicle is selected, the map fades rows unrelated to that selection so the relevant stop remains emphasized. Select the main route shield above the strip to return selection to the displayed route.
