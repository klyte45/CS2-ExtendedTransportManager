Use the diamond button near the right side of the XTM map toolbar to switch the map canvas to a light background.

The option changes the linear map's background to light gray, uses dark inherited text, darkens district boundaries, and adjusts outside-connection labels for contrast. Route colors, stop markers, vehicles, occupancy labels, the toolbar, and the rest of the Selected Info Panel keep their own styling.

This option starts disabled and is retained only while the frontend remains loaded.
