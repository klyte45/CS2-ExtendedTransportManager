XTM extends several existing game screens, but each screen keeps its own mode.

In **Transportation Overview**, the XTM button switches the panel between the original game overview and XTM's management interface. XTM mode contains the line listing, Fare Groups, Vehicle Model Groups, Available palettes, Passenger Occupancy Report, and Cargo Occupancy Report. Use **Change mode** to move between these XTM screens.

![Transportation Overview in XTM listing mode with the Change mode menu listing the six XTM screens](coui://xtm.k45/UI/images/xtm-overview-modes.jpg)

Transportation Overview opens in XTM mode when **Use XTM line listing by default** is enabled. This option is enabled by default. Switching modes affects the current panel session; reopening the panel uses the configured default again.

The **Encyclopedia** has a separate XTM button on the right edge. It normally opens in the original game mode, although an XTM link can open a specific XTM article directly.

A selected route's **linear map** has another independent XTM button. XTM map mode is initially enabled and can show distances, districts, interchanges, vehicles, waiting load, and historical segment occupancy. Switching it off restores the original route visualizer.

XTM also extends the **Selected Info Panel** for routes, stops, and vehicles. Its color, fare-group, vehicle-group, identity, and data controls remain available independently of the Transportation Overview and Encyclopedia modes.
