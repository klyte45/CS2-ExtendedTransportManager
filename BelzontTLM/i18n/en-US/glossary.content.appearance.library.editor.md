**Show palettes button in Editor** is enabled by default in XTM options and is applied when an editor loads.

Select the XTM tool in the Asset Editor toolbar to open the draggable **Available palettes** dialog. It provides the same city-palette list, editing, imports, and transport-type assignments as Transportation Overview.

The dialog edits the current editor world's palette collection; it is not a separate offline library. Use a disk file or bundled preset to transfer an explicit palette source. Select another editor tool when finished.
