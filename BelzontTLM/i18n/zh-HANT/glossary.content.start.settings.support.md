## 取得協助

XTM 選項頁面顯示已安裝的 mod 版本，並提供論壇、來源儲存庫、翻譯資料夾和日誌資料夾的捷徑。

使用論壇獲得玩家支援與討論：[XTM 論壇主題](https://forum.paradoxplaza.com/forum/threads/xtm-extended-transport-manager.1651555/)

使用 GitHub 儲存庫進行原始碼和技術問題追蹤：[klyte45/CS2-ExtendedTransportManager](https://github.com/klyte45/CS2-ExtendedTransportManager)

## 包含哪些內容

在尋求協助之前，請記錄顯示的 XTM 版本以及重現問題所需的步驟。對於錯誤，請暫時啟用偵錯日誌記錄，重現問題一次，然後使用 **前往日誌資料夾** 找到 XTM 日誌。

包括遊戲版本、XTM 版本、相關模組列表、受影響的保存上下文、螢幕截圖和日誌檔案。之後將日誌記錄恢復為正常。
