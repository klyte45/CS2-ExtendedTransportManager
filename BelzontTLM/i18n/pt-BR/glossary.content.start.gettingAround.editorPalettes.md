Habilite **Mostrar botão de paletas do editor** nas opções do mod antes de entrar em um editor de jogo. Essa configuração é habilitada por padrão e aplicada quando o editor é carregado.

Selecione o ícone XTM na barra de ferramentas do editor para abrir a caixa de diálogo arrastável **Paletas disponíveis**. Selecione outra ferramenta de edição quando terminar.

![Caixa de diálogo de paletas disponíveis aberta na ferramenta XTM na barra de ferramentas do Asset Editor](coui://xtm.k45/UI/images/xtm-editor-palettes.jpg)

## Gerenciar paletas

Crie uma paleta, importe um arquivo `.hex` ou importe uma predefinição da biblioteca incorporada do XTM. Selecione uma paleta para renomeá-la, excluí-la, adicionar ou remover cores, editar cores individuais, arrastar cores para uma nova ordem, embaralhá-las ou anexar outra paleta.

Você também pode copiar a paleta como um valor RGB por linha, colar e substituir suas cores ou colar e anexar cores. Pressione **Salvar alterações** para persistir as edições de cores ou **Redefinir alterações** para descartar as edições não salvas.

A seção inferior atribui uma paleta para cada tipo de transporte de passageiros ou carga disponível. Selecione **Cor automática desativada** quando esse tipo não deve usar uma paleta.

## Limites

Uma paleta pode conter no máximo 500 cores. As importações usam arquivos `.hex` contendo valores RGB de seis dígitos. O editor trabalha com a coleção de paletas do mundo atual; use arquivos de disco ou a biblioteca incorporada quando precisar de uma fonte de paleta explícita.
