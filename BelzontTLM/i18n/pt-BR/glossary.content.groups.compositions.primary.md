Cada composição é uma seleção de veículo permitida. O XTM copia a lista de composição ordenada do grupo para cada linha de membro, de forma que múltiplas composições permitem que o jogo escolha entre essas entradas.

A maioria dos modos de passageiros e carga usa um veículo principal. Os grupos de trem de carga, bonde e metrô podem emparelhar um motor primário com um vagão secundário opcional. Os modelos ferroviários de passageiros são tratados como veículos autônomos.

Os cartões mostram o nome do modelo localizado, miniatura, capacidade e, quando disponível, comprimento. Os cartões ferroviários de carga também podem mostrar a contagem de unidades e o comprimento combinado calculado.

Selecione um cartão já selecionado para limpar essa parte de uma composição ou remova toda a composição com o botão de lixeira.
