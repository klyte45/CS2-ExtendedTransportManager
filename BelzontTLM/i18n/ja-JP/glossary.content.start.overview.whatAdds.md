Extended Transport Manager は、別の管理ウィンドウを追加するのではなく、ゲームの既存のトランスポート画面を拡張します。輸送タイプとサービスのフィルター、並べ替え、インライン ID とカラー制御、およびルートの詳細への直接アクセスを備えた、すべての旅客路線と貨物ルートの詳細なリストが提供されます。

XTM は過去の占有状況も記録します。乗客と貨物のレポートでは路線と路線セグメントがランク付けされ、強化された線形路線図では待ち時間、車両位置、インターチェンジ、地区、距離、過去の区間占有率を表示できます。

**運賃グループ** を使用すると、旅客会社がデフォルトの運賃とオプションの時間ごとの例外を共有できます。 **車両モデル グループ** を使用すると、互換性のある旅客路線または貨物路線が許可された車両を共有できます。 **パレット**は、乗客または貨物の輸送タイプごとに色を個別に割り当てますが、個々のルートでは固定色のオーバーライドを維持できます。

ルート、停留所、または車両を選択すると、選択した情報パネルに追加情報が表示されます。 XTM は、ルート識別子と生成されたシールド、グループ割り当て制御、旅行およびメンテナンス データ、およびオプションの Write Everywhere 目的地ブラインド ツールを追加します。

この XTM エンサイクロペディアでは、ゲーム内のこれらの機能について説明します。
