## 組み込みの翻訳

XTM は、サポートされているすべてのゲーム ロケールの基本言語として英語を読み込みます。現在のパッケージには、ポルトガル語 (ブラジル) と韓国語の CSV 翻訳も含まれています。

翻訳されたキーが欠落しているか空白の場合は、英語の CSV 値が使用されます。

## CSV ファイル

メインの **i18n.csv** には言語列が含まれています。 **ko-KR.csv** などの別個の言語ファイルは、その言語がメイン ファイルに列を持たない場合にのみ使用されます。

CSV ファイルはタブで区切られており、ヘッダー行が必要です。中括弧などのプレースホルダーの書式設定は変更しないでください。 CSV 値に改行またはタブが必要な場合は、リテラル シーケンス \n および \t を使用します。

## マークダウン用語集の本文

長い用語集エントリは、**i18n/en-US** でキーごとに 1 つの Markdown ファイルを使用します。他の言語は、独自の言語フォルダーの下にある個々のエントリをオーバーレイできます。翻訳された Markdown ファイルが不足している場合は、英語の本文が自動的に保持されます。

各 Markdown ファイルには、**key:** または **entry:** とそれに続くアセンブルされたローカリゼーション キーを含むフロントマターが必要です。

Markdown 本文は CSV エントリの後に読み込まれるため、Markdown ファイルは同じキーで CSV 値をオーバーライドします。

## 翻訳のテスト

**翻訳フォルダーに移動** を使用して、インストールされている XTM i18n ディレクトリを開きます。ファイルを編集した後、**翻訳の再読み込み**を使用して、ゲームを再起動せずにすべての XTM ローカリゼーション ソースを削除して再構築します。

![フォーラム、リポジトリ、ログ フォルダのショートカットの横に翻訳フォルダとリロード ボタンがあるオプション ページ](coui://xtm.k45/UI/images/xtm-settings-localization-support.jpg)

すでに開いているテキストが視覚的に更新されない場合は、そのパネルを閉じて、リロード後に再度開きます。
