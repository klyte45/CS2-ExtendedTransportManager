## 助けを求める

XTM オプション ページには、インストールされている MOD バージョンが表示され、フォーラム、ソース リポジトリ、翻訳フォルダー、およびログ フォルダーへのショートカットが提供されます。

プレーヤーのサポートとディスカッションにはフォーラムを使用してください: [XTM フォーラム トピック](https://forum.paradoxplaza.com/forum/threads/xtm-extended-transport-manager.1651555/)

ソース コードと技術的な問題の追跡には GitHub リポジトリを使用します: [klyte45/CS2-ExtendedTransportManager](https://github.com/klyte45/CS2-ExtendedTransportManager)

## 含めるもの

助けを求める前に、表示された XTM バージョンと問題の再現に必要な手順を記録してください。エラーの場合は、デバッグ ログを一時的に有効にし、問題を一度再現して、**ログ フォルダーに移動** を使用して XTM ログを見つけます。

ゲームのバージョン、XTM バージョン、関連する MOD リスト、影響を受ける保存コンテキスト、スクリーンショット、ログ ファイルが含まれます。その後、ログを通常に戻します。
