XTM enthält eine schreibgeschützte Voreinstellungsbibliothek, die nach Region und Sammlung in Ordnern organisiert ist. Durchsuchen Sie es über die **Standardbibliothek** oder das Lesezeichen **XTM: Bibliothek** in der Palettenauswahl.

Durch das Importieren einer Voreinstellung wird eine separate Stadtpalette erstellt, die umbenannt und bearbeitet werden kann. Der Städtename verwendet den endgültigen Dateinamen der Voreinstellung ohne den Bibliothekspfad. Sie können die Farben einer Voreinstellung auch an eine vorhandene Stadtpalette anhängen.

Das Bearbeiten der Stadtkopie ändert nie die gebündelte Voreinstellung.
