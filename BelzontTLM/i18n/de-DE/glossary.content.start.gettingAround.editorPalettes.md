Aktivieren Sie **Schaltfläche „Editorpaletten anzeigen“** in den Mod-Optionen, bevor Sie einen Spieleditor aufrufen. Diese Einstellung ist standardmäßig aktiviert und wird angewendet, wenn der Editor geladen wird.

Wählen Sie das XTM-Symbol in der Editor-Symbolleiste aus, um das ziehbare Dialogfeld „Verfügbare Paletten“ zu öffnen. Wenn Sie fertig sind, wählen Sie ein anderes Editor-Tool aus.

![Dialogfeld „Verfügbare Paletten“, geöffnet über das XTM-Tool in der Asset-Editor-Symbolleiste](coui://xtm.k45/UI/images/xtm-editor-palettes.jpg)

## Paletten verwalten

Erstellen Sie eine Palette, importieren Sie eine „.hex“-Datei oder importieren Sie eine Voreinstellung aus der eingebetteten Bibliothek von XTM. Wählen Sie eine Palette aus, um sie umzubenennen, zu löschen, Farben hinzuzufügen oder zu entfernen, einzelne Farben zu bearbeiten, Farben in eine neue Reihenfolge zu ziehen, sie zu mischen oder eine andere Palette anzuhängen.

Sie können die Palette auch als einen RGB-Wert pro Zeile kopieren, ihre Farben einfügen und ersetzen oder Farben einfügen und anhängen. Drücken Sie **Änderungen speichern**, um Farbänderungen beizubehalten, oder **Änderungen zurücksetzen**, um nicht gespeicherte Änderungen zu verwerfen.

Der untere Bereich weist jedem verfügbaren Personen- oder Frachttransporttyp eine Palette zu. Wählen Sie **Automatische Farbe deaktiviert**, wenn dieser Typ keine Palette verwenden soll.

## Grenzen

Eine Palette kann maximal 500 Farben enthalten. Beim Import werden „.hex“-Dateien mit sechsstelligen RGB-Werten verwendet. Der Editor arbeitet mit der aktuellen Palettensammlung der Welt; Verwenden Sie Festplattendateien oder die eingebettete Bibliothek, wenn Sie eine explizite Palettenquelle benötigen.
