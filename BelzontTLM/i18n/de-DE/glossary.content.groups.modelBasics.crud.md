Öffnen Sie **Fahrzeugmodellgruppen**, wählen Sie einen Transporttyp aus und wählen Sie **Fahrzeugmodellgruppe hinzufügen**. Eine neue Gruppe wird mit der lokalisierten unbenannten Bezeichnung geöffnet.

Fügen Sie mindestens eine gültige Komposition hinzu, bevor andere Änderungen gespeichert werden können. Gültige Änderungen werden dann automatisch gespeichert. Namen können bis zu 64 Zeichen lang sein. Ein leerer Name wird zum unbenannten Etikett. Eine gültige Gruppe darf keine verknüpften Linien haben.

Benutzen Sie den Papierkorb-Button der Gruppenkarte und bestätigen Sie den Löschvorgang. Die Mitgliedslinien kehren zu den normalen Fahrzeugauswahlsteuerungen zurück, ihre zuletzt angewendete Modellliste bleibt jedoch bestehen, bis sie normal oder von einer anderen Gruppe geändert wird.
