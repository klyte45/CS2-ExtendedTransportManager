Wählen Sie **Palette importieren**, um eine Dateiauswahl für „.hex“-Dateien zu öffnen. Es beginnt im Palettenordner von XTM und enthält ein Lesezeichen **XTM: Library** für gebündelte Voreinstellungen.

Eine „.hex“-Datei enthält eine sechsstellige RGB-Farbe pro Zeile, mit oder ohne „#“. Der Dateiname wird zum Namen der Stadtpalette. Leere oder ungültige Zeilen werden ignoriert und höchstens die ersten 500 gültigen Farben importiert.

Durch den Import wird eine neue Stadtpalette erstellt, auch wenn eine Palette denselben Namen hat. Um Farben mit einer vorhandenen Palette zu kombinieren, wählen Sie diese aus und verwenden Sie **Palette anhängen**.
