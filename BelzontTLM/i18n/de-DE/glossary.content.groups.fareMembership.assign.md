Öffnen Sie für eine nicht verwaltete Passagierlinie **Ticketpreis** im Bereich „Ausgewählte Informationen“ und verwenden Sie das Zahnradmenü, um eine Tarifgruppe zuzuweisen. Im Menü einer verwalteten Leitung können Sie deren Gruppe bearbeiten, die Leitung entfernen oder in eine andere Gruppe verschieben.

Der Gruppeneditor trennt **Zeilen in dieser Gruppe** von **Verfügbare Zeilen zum Verknüpfen mit dieser Gruppe**. Fügen Sie eine Zeile hinzu oder entfernen Sie sie, entfernen Sie alle Mitglieder oder fügen Sie jede Zeile hinzu, die nach den Filtern „Personentransporttyp“, „Dienststatus“ und „zugewiesene Linien“ übrig bleibt.

Eine Linie kann nur einer Tarifgruppe angehören. Eine Warnung markiert Zeilen, die bereits anderweitig vergeben sind; Wenn Sie hier eine Person hinzufügen, wird die vorherige Mitgliedschaft sofort ersetzt. Inaktive Passagierlinien bleiben weiterhin zuweisbar. Frachtrouten sind nicht aufgeführt.

Durch das Entfernen der Mitgliedschaft bleibt der letzte für die Gruppe gültige Ticketpreis bestehen. Passen Sie es bei Bedarf manuell an.
