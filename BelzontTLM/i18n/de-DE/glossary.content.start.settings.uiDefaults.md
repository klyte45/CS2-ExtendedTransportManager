## Transportübersicht

**XTM-Zeilenliste standardmäßig verwenden** ist standardmäßig aktiviert. Wenn aktiviert, wird die Transportübersicht im XTM-Modus geöffnet. Wenn es deaktiviert ist, wird es mit dem ursprünglichen Spieltisch geöffnet.

Die XTM-Schaltfläche im Panel-Header bleibt immer verfügbar. Durch den Wechsel wird nur die aktuelle Panel-Sitzung geändert; Beim erneuten Öffnen der Transportübersicht wird der konfigurierte Standard erneut gelesen.

Ein direkter Link von einem anderen XTM-Bildschirm kann die Transportübersicht auch dann im XTM-Modus öffnen, wenn die Standardeinstellung deaktiviert ist.

## Editor-Palettentool

**Die Schaltfläche „Paletten anzeigen“ im Editor ist standardmäßig aktiviert. Es fügt das XTM-Palettentool zur Editor-Symbolleiste hinzu und öffnet dort die Benutzeroberfläche „Verfügbare Paletten“.

Diese Option wird ausgewertet, wenn der Editormodus aufgerufen wird. Verlassen Sie den Editor und rufen Sie ihn erneut auf, nachdem Sie ihn geändert haben.

Beim Zurücksetzen der XTM-Einstellungen werden beide UI-Standardeinstellungen auf „Aktiviert“ zurückgesetzt.
