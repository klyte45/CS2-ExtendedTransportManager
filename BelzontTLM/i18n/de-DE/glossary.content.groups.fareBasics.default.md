Der **Standardtarif** wird von jeder Mitgliedslinie verwendet, wenn keine Stundenausnahme die aktuelle Spielzeitstunde abdeckt.

Eine neue Gruppe beginnt mit dem normalen Standardticketpreis des Spiels. Positive Werte, die unter dem zulässigen Minimum des Spiels liegen, können beim Speichern auf dieses Minimum angehoben werden.

Setzen Sie den Fahrpreis für kostenlose Fahrt auf **0**. XTM zeigt Null als **Kostenlos** an und deaktiviert die Ticketpreisrichtlinie auf Mitgliedslinien, solange Null wirksam ist.

Eine Ausnahme kann weiterhin während eines Teils eines kostenlosen Standardtages abgerechnet werden oder einen kostenlosen Zeitraum innerhalb eines kostenpflichtigen Zeitplans erstellen. Gültige Änderungen werden automatisch gespeichert und an alle aktuellen Mitglieder weitergegeben.
