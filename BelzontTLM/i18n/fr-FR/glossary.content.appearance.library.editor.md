**Le bouton Afficher les palettes dans l'éditeur** est activé par défaut dans les options XTM et est appliqué lors du chargement d'un éditeur.

Sélectionnez l'outil XTM dans la barre d'outils de l'éditeur d'actifs pour ouvrir la boîte de dialogue **Palettes disponibles** déplaçables. Il fournit la même liste de palettes de villes, les mêmes modifications, importations et affectations de types de transport que l'Aperçu des transports.

La boîte de dialogue modifie la collection de palettes du monde actuel de l'éditeur ; ce n'est pas une bibliothèque hors ligne distincte. Utilisez un fichier disque ou un préréglage fourni pour transférer une source de palette explicite. Sélectionnez un autre outil d'édition lorsque vous avez terminé.
