Chaque étape contient une ou plusieurs **images clés**. Les stores dynamiques les font défiler pendant leurs durées de trame de simulation configurées. Les stores statiques utilisent uniquement l'image clé statique sélectionnée.

**Nom de l'itinéraire** affiche le nom d'affichage de l'itinéraire. **Arrêt de destination** affiche la limite de l'étape ou le premier arrêt pour la fin de la ligne. Le **numéro d'itinéraire** utilise l'identifiant d'affichage effectif ou le numéro interne. **Texte statique** affiche le texte fixe. **Le prochain arrêt** suit le véhicule. **L'arrêt, le district ou la route de destination** passe par le district, la route ou l'agrégat associé à l'arrêt et constitue la valeur par défaut.

Choisissez **Image clé à utiliser comme store statique** pour les mises en page non animées. Une étape avec une image clé reste naturellement sur cette valeur dans les mises en page dynamiques.
