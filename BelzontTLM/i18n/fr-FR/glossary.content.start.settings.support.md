## Obtenir de l'aide

La page des options XTM affiche la version du mod installée et fournit des raccourcis vers le forum, le référentiel source, le dossier de traduction et le dossier de journaux.

Utilisez le forum pour l'assistance et la discussion des joueurs : [Sujet du forum XTM](https://forum.paradoxplaza.com/forum/threads/xtm-extended-transport-manager.1651555/)

Utilisez le référentiel GitHub pour le code source et le suivi des problèmes techniques : [klyte45/CS2-ExtendedTransportManager](https://github.com/klyte45/CS2-ExtendedTransportManager)

## Que faut-il inclure

Avant de demander de l'aide, enregistrez la version XTM affichée et les étapes nécessaires pour reproduire le problème. En cas d'erreurs, activez temporairement la journalisation du débogage, reproduisez le problème une fois et utilisez **Aller au dossier des journaux** pour localiser le journal XTM.

Incluez la version du jeu, la version XTM, la liste des modules pertinents, le contexte de sauvegarde concerné, les captures d'écran et le fichier journal. Remettez ensuite la journalisation à Normal.
