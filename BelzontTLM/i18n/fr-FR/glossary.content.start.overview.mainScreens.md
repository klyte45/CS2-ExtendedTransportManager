XTM étend plusieurs écrans de jeu existants, mais chaque écran conserve son propre mode.

Dans **Aperçu des transports**, le bouton XTM fait basculer le panneau entre l'aperçu du jeu original et l'interface de gestion de XTM. Le mode XTM contient la liste des lignes, les groupes tarifaires, les groupes de modèles de véhicules, les palettes disponibles, le rapport d'occupation des passagers et le rapport d'occupation du fret. Utilisez **Changer de mode** pour vous déplacer entre ces écrans XTM.

![Aperçu du transport en mode listing XTM avec le menu Changement de mode listant les six écrans XTM](coui://xtm.k45/UI/images/xtm-overview-modes.jpg)

L'aperçu du transport s'ouvre en mode XTM lorsque **Utiliser la liste de lignes XTM par défaut** est activé. Cette option est activée par défaut. Le changement de mode affecte la session de panel en cours ; la réouverture du panneau utilise à nouveau la valeur par défaut configurée.

L'**Encyclopédie** comporte un bouton XTM distinct sur le bord droit. Il s'ouvre normalement dans le mode de jeu original, bien qu'un lien XTM puisse ouvrir directement un article XTM spécifique.

La **carte linéaire** d'un itinéraire sélectionné possède un autre bouton XTM indépendant. Le mode carte XTM est initialement activé et peut afficher les distances, les quartiers, les échangeurs, les véhicules, la charge en attente et l'occupation historique des segments. Le désactiver restaure le visualiseur d'itinéraire d'origine.

XTM étend également le **Panneau d'informations sélectionnées** pour les itinéraires, les arrêts et les véhicules. Ses contrôles de couleur, de groupe tarifaire, de groupe de véhicules, d'identité et de données restent disponibles indépendamment des modes Aperçu du transport et Encyclopédie.
