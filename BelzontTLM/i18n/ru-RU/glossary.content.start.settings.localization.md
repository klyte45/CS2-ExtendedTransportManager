## Встроенные переводы

XTM загружает английский в качестве базового языка для каждой поддерживаемой локали игры. Текущий пакет также содержит переводы CSV на португальский (Бразилия) и корейский языки.

Если переведенный ключ отсутствует или пуст, используется значение CSV на английском языке.

## CSV-файлы

Основной файл **i18n.csv** содержит языковые столбцы. Отдельный языковой файл, например **ko-KR.csv**, используется только в том случае, если для этого языка нет столбца в основном файле.

Файлы CSV разделены табуляцией и требуют строки заголовка. Оставьте без изменений форматирование заполнителей, таких как фигурные скобки. Используйте литеральные последовательности \n и \t, если для значения CSV требуется разрыв строки или табуляция.

## Тела глоссария Markdown

В длинных статьях глоссария используется один файл Markdown для каждого ключа в разделе **i18n/en-US**. Другие языки могут накладываться на отдельные записи в своей языковой папке. Отсутствующий переведенный файл Markdown автоматически сохраняет английское тело.

Для каждого файла Markdown требуется заголовок, содержащий **key:** или **entry:**, за которым следует собранный ключ локализации.

Тела Markdown загружаются после записей CSV, поэтому файл Markdown переопределяет значение CSV с тем же ключом.

## Тестирование переводов

Используйте **Перейти к папке «Переводы»**, чтобы открыть установленный каталог XTM i18n. После редактирования файла используйте **Обновить переводы**, чтобы удалить и пересобрать все источники локализации XTM без перезапуска игры.
