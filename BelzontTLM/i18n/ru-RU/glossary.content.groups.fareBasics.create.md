Откройте **Обзор транспорта**, выберите **Изменить режим**, затем **Тарифные группы**. Нажмите кнопку «плюс» рядом с «Группы», чтобы создать группу.

Новая группа выбирается автоматически, начинается с обычного тарифа билета игры по умолчанию и использует **Безымянную группу** до тех пор, пока она не будет переименована. Имена сохраняются по завершении редактирования; пустое имя возвращается к локализованной безымянной метке.

На каждой групповой карточке указано ее имя, тариф по умолчанию и количество участников. Выберите карточку, чтобы отредактировать ее.

Используйте кнопку «Корзина» на карточке и подтвердите удаление группы. Его линии перестают принадлежать к этой группе, но сохраняют последний примененный тариф XTM. Просмотрите цены на билеты после удаления.
