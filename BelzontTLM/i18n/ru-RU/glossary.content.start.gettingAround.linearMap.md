Выберите транспортный маршрут и найдите визуализатор его линий на **Панели выбранной информации**. Используйте кнопку XTM слева на панели инструментов визуализатора, чтобы переключаться между эскизом игрового маршрута и линейной картой XTM.

## Элементы управления картой

На карте могут отображаться расстояния, границы районов, транспортные средства, соединительные линии, загруженность платформ, занятость сегментов, белый фон и сокращенный вид половины пути для симметричных маршрутов.

![Линейная карта XTM с панелью инструментов и включенными наложениями расстояний, районов, соединений, скопления людей и занятости](coui://xtm.k45/UI/images/xtm-linear-map-overlays.jpg)

Загруженность сегмента может быть скрыта или отображена для текущего часа, среднего значения за день или одного из шести четырехчасовых периодов. Выберите значение занятости сегмента, чтобы открыть его историческую диаграмму.

![Детали занятости сегмента открываются на линейной карте с временной диаграммой и средним значением за день](coui://xtm.k45/UI/images/xtm-linear-map-segment-detail.jpg)

## Навигация по карте

Выберите остановку, чтобы сфокусировать ее, и откройте данные остановки. Когда отобразятся транспортные средства, выберите один из них, чтобы сфокусировать его, и откройте «Данные о транспортном средстве». Выберите щит соединительной линии, чтобы перейти к этому маршруту. Выберите щит основного маршрута, чтобы вернуться к маршруту.

## Значения по умолчанию и ограничения

Режим карты XTM запускается включенным. Включены расстояния, районы, соединительные линии, загруженность платформ, текущая занятость сегмента и симметричный запуск режима полупоезда; транспортные средства и запуск на белом фоне отключены.

Транспортные средства и соединительные линии являются взаимоисключающими. Режим полупути используется только для обнаруженного симметричного маршрута, когда транспортные средства скрыты.
