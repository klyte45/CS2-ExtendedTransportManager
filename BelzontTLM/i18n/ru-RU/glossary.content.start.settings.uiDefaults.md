## Обзор транспорта

**Использовать список строк XTM по умолчанию** включен по умолчанию. Если этот параметр включен, обзор транспорта открывается в режиме XTM. При отключении открывается исходный игровой стол.

Кнопка XTM в заголовке панели всегда остается доступной. Его переключение меняет только текущий сеанс панели; при повторном открытии обзора транспорта снова считывается настроенное значение по умолчанию.

Прямая ссылка с другого экрана XTM по-прежнему может открыть «Обзор транспорта» в режиме XTM, даже если режим по умолчанию отключен.

## Инструмент «Редактор палитры»

**Кнопка «Показать палитры в редакторе»** включена по умолчанию. Он добавляет инструмент «Палитра XTM» на панель инструментов «Редактор», где открывается интерфейс «Доступные палитры».

Эта опция оценивается при входе в режим редактора. Выйдите из редактора и снова войдите в него после внесения изменений.

Оба значения пользовательского интерфейса по умолчанию восстанавливаются до значения «включено» при сбросе настроек XTM.
