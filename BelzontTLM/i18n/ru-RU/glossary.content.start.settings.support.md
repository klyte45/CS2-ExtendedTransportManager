## Получение помощи

На странице параметров XTM отображается установленная версия мода и имеются ярлыки для форума, исходного репозитория, папки перевода и папки журнала.

Используйте форум для поддержки и обсуждения игроков: [тема форума XTM](https://forum.paradoxplaza.com/forum/threads/xtm-extended-transport-manager.1651555/)

Используйте репозиторий GitHub для отслеживания исходного кода и технических проблем: [klyte45/CS2-ExtendedTransportManager](https://github.com/klyte45/CS2-ExtendedTransportManager)

## Что включить

Прежде чем обращаться за помощью, запишите отображаемую версию XTM и действия, необходимые для воспроизведения проблемы. В случае ошибок временно включите ведение журнала отладки, воспроизведите проблему один раз и используйте **Перейти в папку журнала**, чтобы найти журнал XTM.

Укажите версию игры, версию XTM, соответствующий список модов, затронутый контекст сохранения, снимки экрана и файл журнала. После этого верните ведение журнала в обычный режим.
