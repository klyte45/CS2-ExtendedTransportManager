XTM расширяет несколько существующих игровых экранов, но каждый экран сохраняет свой режим.

В **Обзоре транспорта** кнопка XTM переключает панель между исходным обзором игры и интерфейсом управления XTM. Режим XTM содержит список строк, группы тарифов, группы моделей транспортных средств, доступные палитры, отчет о занятости пассажиров и отчет о занятости груза. Используйте **Изменить режим** для перемещения между этими экранами XTM.

![Обзор транспорта в режиме списка XTM с меню режима изменения, в котором перечислены шесть экранов XTM](coui://xtm.k45/UI/images/xtm-overview-modes.jpg)

Обзор транспорта открывается в режиме XTM, если включен параметр **Использовать список строк XTM по умолчанию**. Эта опция включена по умолчанию. Переключение режимов влияет на текущий сеанс панели; при повторном открытии панели снова используется настроенное значение по умолчанию.

В **Энциклопедии** есть отдельная кнопка XTM на правом краю. Обычно он открывается в исходном игровом режиме, хотя ссылка XTM может открыть конкретную статью XTM напрямую.

На **линейной карте** выбранного маршрута имеется еще одна независимая кнопка XTM. Режим карты XTM изначально включен и может отображать расстояния, районы, развязки, транспортные средства, ожидающую нагрузку и историческую занятость сегментов. Отключение восстанавливает исходный визуализатор маршрута.

XTM также расширяет **Панель выбранной информации** для маршрутов, остановок и транспортных средств. Элементы управления цветом, тарифной группой, группой транспортных средств, идентификацией и данными остаются доступными независимо от режимов «Обзор транспорта» и «Энциклопедия».
