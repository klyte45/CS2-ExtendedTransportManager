Выберите **Импортировать палитру**, чтобы открыть средство выбора файлов для файлов `.hex`. Он запускается в папке палитры XTM и включает закладку **XTM: Library** для связанных пресетов.

Файл `.hex` содержит один шестизначный цвет RGB в каждой строке, с символом "#" или без него. Имя файла становится именем городской палитры. Пустые или недопустимые строки игнорируются, и импортируются не более первых 500 допустимых цветов.

Импорт создает новую палитру города, даже если палитра имеет то же имя. Чтобы объединить цвета с существующей палитрой, выберите ее и используйте **Добавить палитру**.
