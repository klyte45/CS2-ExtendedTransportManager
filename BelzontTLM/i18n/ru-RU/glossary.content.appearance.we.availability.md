Для жалюзи назначения XTM требуется **Write Everywhere** («BelzontWE»). Когда этот мод присутствует и XTM может прикрепить свои крючки для интеграции, жалюзи доступны для каждой транспортной линии.

Выберите маршрут и откройте **Данные линии**. Кнопка «Написать везде» открывает перетаскиваемое окно **Написать везде — Пользовательские жалюзи**. Кнопка не отображается для выбора остановки или транспортного средства.

Без Write Everywhere кнопка и редактирование без указания места назначения недоступны. Вся эта категория энциклопедии **Пиши везде** также опущена.
